# MafiaWeb.LogicTests

Постоянный консольный regression harness для реального `GameRoomService`, .NET 8, без NuGet-пакетов и ProjectReference.

## Запуск

Из корня `C:\dev\csharp\MafiaWeb`:

```powershell
dotnet run --project tests/MafiaWeb.LogicTests/build/MafiaWeb.LogicTests.csproj
```

Нужен установленный .NET SDK с поддержкой net8.0 и runtime .NET 8. Код возврата 0 — все сценарии прошли, 1 — есть ошибки. Каждый сценарий печатает PASS/FAIL; при ошибке выводятся assertion и stack trace. Итог — строка RESULT. Это не `dotnet test`: внешние тестовые фреймворки не используются.

## Структура и интеграция

Проект намеренно находится в подкаталоге `build/`: отсюда требуемые ссылки `../../../Models/*.cs` и `../../../Services/GameRoomService.cs` разрешаются непосредственно в исходники MafiaWeb. Из самого `tests/MafiaWeb.LogicTests/` такой путь был бы ошибочным: понадобилось бы `../../`. Реальные исходники компилируются заново при каждом запуске, копий сервиса и mock-реализаций нет.

**Важно:** основной `MafiaWeb.csproj` должен исключать `tests/**/*.cs` из Compile (например, `<Compile Remove="tests/**/*.cs" />`), включая генерируемые вложенные `obj` файлы. Основной проект данным заданием не изменяется.

## Покрытие

- Готовность всех занятых мест, перенос места, сброс готовности.
- Ровно 60 тиков нулевой ночи и речи; переключение на последнем тике.
- Третий фол текущему/будущему спикеру, одноразовый пропуск, запрет номинации вне своей речи; три выкрика и их шестисекундное завершение.
- Один кандидат в первый и последующие дни — ночь без удаления.
- Автоматические голоса последнему кандидату, мертвые кандидаты, очистка голосов и недействительность голосов мертвых.
- Ничья, отдельные 30-секундные речи, повторное голосование, повторная ничья и GroupVoting.
- Строгое большинство всех живых, воздержание против; групповое удаление всех до проверки победы.
- Паритет в столах 8/10 и специальная логика четырех игроков.
- Распределение ролей для 4/8/10/12; приватность ролей и mafia count, раскрытие после конца игры.
- Проверки шерифа/дона: права, приватность, одна проверка за ночь и сброс ограничения.
- Согласованная стрельба, разные цели, отсутствующий выстрел, запреты мертвых и собственных целей.
- Смерть спикера не зацикливает дневной круг.

Настройка ролей и отдельных пограничных состояний выполняется детерминированно через публичные mutable `PlayerSlot` из `GetSlots()`. Private-поля, reflection, реальные задержки и сетевой хост не используются. SignalR-рассылка таймера не тестируется: здесь проверяются только состояние сервиса и возвращаемый признак перехода в TickSecond.
